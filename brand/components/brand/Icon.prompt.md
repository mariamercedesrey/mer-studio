The Agente Mamá AI client icon (house outline + heart) from the MER client marquee — use only when showing that client's mark.

```jsx
<Icon type="positive" />
<Icon type="negative" style={{ width: 39.683, height: 39.683 }} />
```

- `type`: `positive` (dark house, terracotta heart), `negative` (light house for dark grounds), `alternative` (dark house, light heart).
- Not a general-purpose icon set — MER has no UI icon library in the Figma file.
